SaaS Project Management Dashboard
A lightweight, browser-based project management application built entirely with HTML, CSS, and JavaScript — no frameworks, no backend, no installation required.

Open index.html in any modern browser and start managing projects immediately.

✨ Features
🔐 User Authentication — Sign up and log in with password hashing

👑 Role-Based Access — First registered user becomes admin; others are members

✅ Task Management — Create, assign, and track tasks through statuses (To Do → In Progress → Done)

👥 Team Management — View all team members with per-member task counts

📊 Progress Analytics — Live progress bar and status breakdown cards

⚙️ Admin Dashboard — Admin-only view of all users and all tasks

💾 Data Persistence — All data saved to browser localStorage (survives refresh)
